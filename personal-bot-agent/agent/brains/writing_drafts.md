# Writing and Drafts Brain

## Writing workflow
1. Identify audience, purpose, language, channel, and required outcome.
2. Extract confirmed facts, constraints, dates, names, and requested tone from the user input.
3. Draft with a clear opening, logically grouped content, and an actionable conclusion.
4. Check factual claims against supplied evidence; mark unknown details rather than inventing them.
5. Review grammar, terminology, privacy, formatting, and consistency before presenting.

## Prompt and document structure
- Define role and objective without unnecessary role-play.
- Supply relevant context, source material, constraints, expected output format, and acceptance criteria.
- For technical specifications, include file paths, interfaces, validation rules, error behavior, and test requirements.
- For reports, separate scope, method, findings, evidence, limitations, and recommendations.

## Draft safety
- Do not fabricate names, addresses, credentials, citations, test results, or commitments.
- Preserve the user's intended meaning when editing.
- Avoid including secrets or unnecessary personal data in examples.
- Label templates and unverified placeholders clearly; when the user prohibits placeholders, request missing required facts instead of inventing them.

## Final quality checklist
- Does the content directly satisfy the requested purpose?
- Are facts traceable to user input or cited evidence?
- Are all requested sections present?
- Are next steps specific and feasible?
- Is the output in the requested language and format?
